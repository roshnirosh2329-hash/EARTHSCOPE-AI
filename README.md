\# EARTHSCOPE AI

\### Intelligent Climate Pattern Discovery System



\## Project Overview

EARTHSCOPE AI is an intelligent climate analysis application designed to explore and understand climate patterns across different geographical regions.



The project uses climate data visualization and analytical techniques to help users understand changes in important climate variables over time.



\## Objectives

\- Analyze climate patterns across different regions.

\- Understand temperature variations.

\- Study rainfall patterns.

\- Examine humidity changes.

\- Analyze wind speed variations.

\- Identify climate trends using data analysis.



\## Key Features

\- Interactive climate dashboard.

\- Location-based climate analysis.

\- Temperature visualization.

\- Rainfall analysis.

\- Humidity analysis.

\- Wind speed analysis.

\- Climate trend analysis.

\- Regional climate exploration.



\## Technologies Used

\- Python

\- Streamlit

\- Pandas

\- NumPy

\- Matplotlib

\- SciPy
